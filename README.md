# Portfolio Cybersécurité - Daouda Sow

Un portfolio interactif sur le thème cyberpunk / hacker, conçu pour présenter mes compétences et projets en cybersécurité.

![Aperçu du Portfolio](https://img.shields.io/badge/Status-En_ligne-brightgreen)
![Technologies](https://img.shields.io/badge/Tech-HTML5_|_CSS3_|_Vanilla_JS-blue)

## 🚀 Fonctionnalités

- **Thème Cyberpunk / Neon :** Design sombre avec des effets de lueur néon (vert et cyan) inspiré de l'esthétique hacker.
- **Effet "Matrix Digital Rain" :** Animation en arrière-plan générée dynamiquement avec un `<canvas>` HTML5 et JavaScript.
- **Terminal Interactif :** Simulation de terminal avec effet de frappe au clavier pour la section "À propos".
- **Design Responsive :** S'adapte parfaitement aux écrans d'ordinateurs, tablettes et smartphones.
- **Animations Fluides :** Transitions douces au survol, apparitions progressives et effets de glitch.

## 🛠️ Technologies Utilisées

Ce projet a été développé de zéro, sans l'utilisation de frameworks lourds, pour garantir des performances optimales et une personnalisation totale :

- **HTML5 :** Structure sémantique de la page.
- **CSS3 :** 
  - Variables CSS pour une gestion facile du thème.
  - Flexbox et CSS Grid pour la mise en page.
  - Animations et transitions personnalisées (keyframes).
  - Media queries pour l'adaptation mobile.
- **JavaScript (Vanilla) :**
  - Logique de l'animation de la pluie de code Matrix.
  - Script pour l'effet de machine à écrire (Typewriter effect) dans le terminal.
  - Gestion des interactions utilisateur.

## 💻 Installation en Local

Pour lancer ce projet sur votre machine locale :

1. Clonez ce repository :
   ```bash
   git clone https://github.com/Poulo22/portfolio.git
   ```
2. Ouvrez le dossier du projet :
   ```bash
   cd portfolio
   ```
3. Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré. Aucun serveur n'est requis.
